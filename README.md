# my-website

This is a simple static website for Naima with a chill & cozy concept.

Files added:

- [index.html](index.html) — the main single-page site with six sections.
- [styles.css](styles.css) — site styles using light beige, white and pink colors.

Open [index.html](index.html) in your browser to view the site. The gallery currently displays visible placeholder images (SVG data URIs) so the page shows images — replace the `img` src attributes in `index.html` with direct image URLs if you want the real pin images.
